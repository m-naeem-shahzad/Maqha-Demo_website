MAQHA COFFEE CULTURE — WEBSITE CONCEPT DEMO

Files:
- index.html: website structure
- styles.css: responsive design and styling
- script.js: navigation, menu filters, demo basket, newsletter demo
- assets/: local logo and image assets

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or use VS Code Live Server for the best preview.

NOTES
- This is a front-end concept/demo only. It does not process real orders or payments.
- The basket is an interactive visual demo.
- Newsletter form is not connected to an email marketing service.
- Instagram section is an Instagram-style static concept using the same local café images as the website; it is not a live Instagram API feed. Replace the sample cards/captions with Maqha-approved posts before launch.
- Sample guest notes are placeholders and must be replaced with approved, verified customer reviews before launch.
- Opening hours and address are based on the supplied Instagram profile screenshot.
- Breakfast prices were not visible in the supplied menu image, so the demo says “Ask in café”.
- Fonts load from Google Fonts; if offline, fallback fonts are used.
- Please confirm all menu items, prices, business details, and image permissions with Maqha before publishing.
